# Easy Switch Controller for Android

Logitech 마우스와 키보드의 Easy-Switch 채널을 Android에서 전환하는 비공식 앱입니다. 키보드의 Easy-Switch 키를 눌렀을 때 마우스를 같은 채널로 따라가게 하거나, 앱과 플로팅 버튼에서 선택한 기기를 함께 전환할 수 있습니다.

Logitech과 제휴하거나 Logitech이 제공하는 앱은 아닙니다. 제품명과 상표는 연결할 기기를 설명하기 위해 사용합니다.

[릴리즈와 APK 다운로드](https://github.com/ikjudang/logitech-easy-switch-controller-android/releases)

## 지원 범위

- Android에 Bluetooth로 페어링한 호환 기기를 사용합니다. 앱은 시스템에 등록된 기기 목록에서 전환 대상을 선택합니다.
- 기기의 전환 기능과 연결 방식이 이 앱의 통신 방식과 호환돼야 합니다. Bluetooth로 연결된다는 이유만으로 모든 제품을 지원하는 것은 아닙니다.
- 현재 구현은 Bluetooth 직접 연결을 대상으로 합니다. USB 수신기 제어는 구현돼 있지 않습니다.
- APK는 실험판으로 배포합니다. 현재 확인 중인 동작은 각 릴리즈 설명을 확인해 주세요.

## 설치와 처음 사용하기

1. 릴리즈 페이지에서 `EasySwitch` APK를 내려받아 설치합니다. GitHub의 `Source code` 압축 파일은 설치 파일이 아닙니다.
2. Android의 Bluetooth 설정에서 사용할 기기를 페어링합니다.
3. 앱을 열고 주변 기기 권한을 허용합니다.
4. 기기 선택 화면에서 앱이 제어할 마우스와 키보드를 선택합니다.
5. 홈의 채널 버튼을 눌러 수동 전환하거나, 연결된 키보드의 Easy-Switch 키를 사용합니다.

같은 앱 패키지와 서명으로 만든 배포 APK는 기존 설치본 위에 업데이트할 수 있습니다. 다른 서명의 개발용 APK는 배포 APK 위에 업데이트 설치할 수 없습니다.

## 기기 전환

### 키보드 따라가기

앱은 연결된 선택 키보드의 전환 신호를 감시하고, 신호를 받으면 선택한 마우스에 같은 채널로 전환하도록 명령합니다. 앱 화면을 열면 따라가기 서비스를 시작하며, 재부팅이나 앱 업데이트 뒤에도 서비스를 다시 시작하도록 구성돼 있습니다. 권한과 Android의 서비스 실행 조건을 충족해야 동작합니다.

키보드가 앱의 감시 연결과 무관하게 자체적으로 전환되는 동작은 그대로 유지됩니다. 연결되지 않았다고 확인된 마우스는 이번 따라가기 대상과 결과에서 제외합니다.

### 앱에서 함께 전환하기

홈이나 플로팅 메뉴의 채널을 선택하면, 앱은 선택된 연결 기기의 전환 명령을 서로 기다리지 않고 시작합니다. 실제로 전환을 끝내는 시점은 기기마다 다를 수 있습니다.

홈의 채널 이름은 길게 누르거나 마우스로 우클릭해서 편집할 수 있습니다. 기기 선택은 일시적인 목록 조회 실패만으로 지우지 않으며, 재등록된 기기의 이름을 기준으로 선택을 복원하는 처리도 포함합니다.

### 홈의 채널 표시

| 표시 | 의미 |
| --- | --- |
| 현재 기기 연결 중 | 앱이 현재 Android에 연결된 기기의 채널로 확인한 상태입니다. |
| 마지막 전환 채널 | 앱이 마지막으로 명령을 보내거나 전환 신호를 관측한 채널입니다. 상대 기기가 지금도 그 채널을 사용한다는 뜻은 아닙니다. |

다른 호스트 사이에서 일어난 전환까지 이 Android 앱이 계속 추적하는 것은 아닙니다. 마지막 전환 표시와 현재 Android 연결 표시는 구분해서 보여 줍니다.

## 전환·연결 안내

안내는 앱 아이콘과 함께 표시됩니다. 전환 안내에는 채널 제목 아래에 실제 기기 이름과 상태를 별도 행으로 표시합니다.

- `전환 중`: 앱이 해당 전환의 결과를 기다리는 상태입니다.
- `완료`: 앱이 관측할 수 있는 연결 상태가 전환 확인 조건을 충족한 상태입니다.
- `실패`: 명령 전달에 실패했거나 전환 확인 조건을 충족하지 못한 상태입니다.
- `확인 필요`: 앱이 결과를 확정할 수 없는 상태입니다.

완료와 실패는 글자 색으로도 구분합니다. 늦게 확인된 기기의 결과는 같은 전환 안내에 반영합니다. 대상이 없으면 `전환할 기기가 없음`으로 안내합니다.

연결 안내도 실제 기기 이름과 `연결됨`을 별도 행으로 표시합니다. 함께 연결된 기기는 묶어서 안내할 수 있습니다. 같은 연결에 대한 중복 시스템 이벤트를 새 연결처럼 반복 안내하지 않습니다.

전환의 완료 표시는 앱이 관측한 결과입니다. 연결이 끊긴 뒤 목적지 호스트에 정상적으로 도착했는지까지 보장하는 표시는 아닙니다.

## 플로팅 버튼

설정에서 **다른 앱 위에 표시**를 허용한 뒤 **플로팅 버튼**을 켜면 홈 화면과 다른 앱 위에서 사용할 수 있습니다. 앱과 같은 전환 대상 설정을 사용합니다.

- 홈 버튼을 누르면 채널 버튼과 `App` 버튼이 펼쳐집니다. `App`은 Easy Switch 앱을 엽니다.
- 홈 버튼을 끌어서 위치를 옮길 수 있습니다. 메뉴는 화면 테두리를 고려해 배치됩니다.
- 마우스 호버와 터치에 반응하며, 선택한 버튼과 나머지 버튼을 구분해서 표시합니다.
- 일반 메뉴는 버튼 바깥을 누르면 접힙니다.
- 홈 버튼을 길게 누르거나 우클릭하면 숨김용 `X`가 나타납니다. 홈 버튼을 `X` 쪽으로 끌어 놓아 숨길 수 있습니다.
- 키보드의 전환 신호를 받았을 때 하위 버튼이 펼쳐져 있으면 해당 채널의 선택 연출을 보여 줍니다. 이 피드백을 위해 전환 명령을 다시 보내지는 않습니다.

### 플로팅 설정

| 항목 | 동작 |
| --- | --- |
| 투명도 | 숫자 입력 또는 슬라이더로 표시 농도를 조절합니다. |
| 크기 | 홈·하위 버튼과 숨김 버튼의 크기를 함께 조절합니다. 열린 메뉴도 함께 조절합니다. |
| 애니메이션 속도 | 펼침·흡수·호버·디밍과 바운스의 재생 속도를 조절합니다. |
| 하위 버튼 항상 표시 | 하위 메뉴가 펼쳐진 상태를 유지합니다. 끄면 하위 버튼이 접힙니다. |
| 바운스 애니메이션 | 바운스 동작을 켜거나 끕니다. 호버·디밍과 메뉴의 펼침·흡수는 기본 동작으로 유지합니다. |

버튼이 실제 표시 중이면 설정 행에 **사용 중**을 표시합니다. 표시되지 않으면 **켜기**로 다시 표시할 수 있습니다. 크기나 투명도 설정 때문에 버튼이 보이지 않는 상태에서는 값을 임의로 바꾸지 않고 하위 설정을 펼칩니다.

### 숨긴 버튼 다시 표시하기

- 앱의 **플로팅 버튼** 알림을 누릅니다. 알림을 사용하려면 Android에서 알림 표시를 허용해야 합니다.
- 빠른 설정 편집 화면에 **플로팅 버튼** 타일을 추가한 뒤 타일을 누릅니다.
- 앱 설정의 **켜기**를 사용합니다.
- Easy Switch 앱 화면에서 마우스 좌우 버튼을 함께 눌러 포인터 위치에 표시할 수 있습니다. 다른 앱에서 전역으로 입력을 가로채는 기능은 아닙니다.

버튼을 표시할 조건이 갖춰지지 않았으면 알림이나 타일은 앱을 엽니다. 플로팅 기능이 켜진 상태에서 앱 알림이 삭제되면 다시 표시하도록 구성돼 있지만, 사용자가 시스템에서 알림 자체를 차단한 상태까지 해제하지는 않습니다.

## 권한과 시스템 알림

| 항목 | 필요한 경우 |
| --- | --- |
| 주변 기기 | 등록된 Bluetooth 기기를 조회하고 연결·제어할 때 필요합니다. |
| 다른 앱 위에 표시 | 다른 앱 위의 안내와 플로팅 버튼을 사용할 때 필요합니다. 설정에서 시스템 허용 화면을 열 수 있습니다. |
| 알림 | 플로팅 버튼을 다시 표시하는 앱 알림에 사용합니다. 필요한 조건에서 앱이 권한을 요청합니다. |

현재 앱은 접근성 서비스를 사용하지 않습니다. 다른 앱 위 표시 권한이 없어도 기기 따라가기와 앱 안의 안내를 사용할 수 있습니다.

앱의 **플로팅 버튼** 알림과 Android가 표시하는 **다른 앱 위에 표시됨** 알림은 서로 다릅니다. 시스템 알림의 표시·정렬은 Android가 관리합니다.

## 설정과 로그

- **마우스 상시 연결**: 앱이 선택한 마우스의 통신 연결을 유지하도록 설정합니다. 필요한 연결 경로를 비교할 때 켜거나 끌 수 있습니다.
- **로그 자동 저장**: 연결·전환 기록을 파일에 남깁니다. 새 설치에서는 사용자가 켜서 사용하며, 하위 메뉴에서 저장 폴더를 선택하거나 변경할 수 있습니다.
- **로그 내보내기**: 선택한 폴더에 현재 기록을 저장하거나 시스템의 저장 위치 선택 기능을 사용합니다. 앱이 자체 클라우드 동기화를 제공하는 기능은 아닙니다.
- **언어**: 한국어와 English를 선택할 수 있습니다.

폰에서는 연결 로그 화면을 열어 기록을 확인하고, 넓은 화면에서는 설정과 함께 로그를 표시합니다.

### 펌웨어 복귀 시험

연결 로그 영역의 시험 도구에서, 선택한 연결 마우스에 전환 명령을 보낸 뒤 펌웨어가 스스로 돌아오는지를 관찰할 수 있습니다. 앱이 강제로 원래 채널로 돌려놓는 기능은 아닙니다.

사용자가 연결할 기기가 없는 목적지를 선택해야 하며, 시험 중에는 다른 채널 전환을 피해야 합니다. 마우스가 돌아오지 않으면 시험을 끝낸 뒤 마우스 자체 버튼으로 원래 채널을 선택합니다. 결과는 연결 로그와 파일에 남깁니다.

## 현재 확인 중인 동작

Bluetooth 입력 장치가 연결되거나 해제될 때, 일부 Android 환경에서 시스템 화면 전환이 오버레이를 잠시 가리는 현상을 확인했습니다. 앱이 그리기를 멈춘 경우와 시스템이 그 위를 가리는 경우를 구분해서 조사 중입니다. 이 현상을 해결 완료로 표시하지 않습니다.

## 소스와 배포

공개 저장소에는 앱 기능 코드와 일반 정지 이미지·SVG·아이콘이 포함됩니다. 플로팅 렌더링·애니메이션 구현과 관련 원본, 상세 사양, 내부 계획·이력은 로컬 전용으로 관리합니다. [공개 이미지 참고 자료](docs/handoff/README.md)를 볼 수 있습니다.

따라서 공개 저장소를 복제하거나 GitHub의 `Source code` 압축 파일을 받는 것만으로 전체 앱을 빌드할 수는 없습니다. 앱을 설치하려면 릴리즈에 첨부된 APK를 사용해 주세요.

배포 APK는 로컬의 전체 소스로 서명 빌드하고 검증한 뒤 릴리즈에 첨부합니다. 해시 파일이 함께 제공되며, 서명 키와 비밀번호는 저장소에 보관하지 않습니다.

기존 태그 자동 빌드 워크플로는 저장소에 남아 있습니다. 현재 공개 소스와 서명 설정만으로 배포를 완료할 수 없으므로 현재 배포 절차로 사용하지 않습니다. 자동 작업의 실패 여부와 별개로, 게시한 APK는 로컬에서 빌드·검증한 파일입니다.
